# NOOVA ERP

Sistema interno para apoyar procesos administrativos, comerciales y operativos de Noova Consulting. El proyecto reúne módulos para clientes, cotizaciones, ventas, compras, operaciones, usuarios y reportes.

Este repositorio es privado y el código corresponde a un sistema empresarial. No publiques datos reales, credenciales ni configuraciones de producción.

## Tecnologías

- React 19 y JavaScript.
- Vite y React Router.
- Firebase Authentication, Firestore y Cloud Functions.
- Chart.js para gráficos.
- jsPDF para documentos PDF.

## Desarrollo local

```bash
npm install
npm run dev
```

Para revisar cambios antes de desplegar:

```bash
npm run lint
npm run build
```

La configuración local se mantiene en archivos de entorno ignorados por Git. Usa `.env.example` como referencia y solicita los valores al administrador del proyecto.
